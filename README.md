I'm a backend engineer at **[Quickeee](https://www.linkedin.com/company/quickeee)**, a quick-commerce startup in Mumbai, working on the systems behind catalogue, pricing, and order fulfillment — a NestJS/PostgreSQL platform handling real production traffic. I care most about the parts of engineering that show up after the happy path: retries, partial failures, idempotency, edge cases.

**Recent, concretely:**

- Rebuilt a synchronous CSV export into a streaming, BullMQ-backed pipeline with a column-selection registry — new report types now ship without a migration
- Re-architected store-level pricing around purchase orders and a scoped (Global / City / Store) discount engine
- Traced a production incident blocking purchase-order creation to two independent root causes across two services
- Built a Google Merchant Center sync module — weekly full-catalogue sync plus a real-time outbox for price/stock/lifecycle changes
- Shipped a GST-aware (CGST/SGST/IGST) Tally purchase-voucher integration
